Pure Node 22 in-memory GitHub-compatible git forge built from scratch using standard library primitives (`node:http`, `node:crypto`, `node:zlib`). Serves Git Smart HTTP (`upload-pack` protocol v2 + v0 fallback, `receive-pack` v0), REST v3 (`/api/v3`), GraphQL v4 (`/api/graphql`), and Streamable HTTP MCP (`2026-07-28` + `2025-11-25`) over a unified deterministic store.

## Run it

```sh
node --experimental-strip-types main.ts
```
